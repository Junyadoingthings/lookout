# Lookout console

The Next.js app for Lookout. See the [root README](../README.md) for the full project.

```bash
npm install
npm run dev      # http://localhost:3000
npm run check    # typecheck, lint, format check, unit tests
npm run build
npm run test:e2e
```

Environment variables are documented in [../.env.example](../.env.example). Copy the console ones into `app/.env.local`.
